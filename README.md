# net-gui-client

Десктопный GUI-клиент для VPN- и прокси-протоколов: SOCKS5, VLESS (+TLS / REALITY / XTLS-Vision), Hysteria2, AmneziaWG, WireGuard, VMess, Trojan, Shadowsocks.

> ⚠️ **Проект в ранней разработке.** Готового к использованию релиза пока нет.

## Что умеет (целевая функциональность)

**Три режима работы** — прокси, системный прокси, полный туннель. Режим является пресетом политики; механизм перехвата выбирается автоматически по тому, что требуют правила.

**Раздельная маршрутизация** по приложениям и сайтам, с двумя политиками: «только выбранное через туннель» и «всё через туннель, кроме выбранного». Плюс действие «блокировать».

**Резервирование путей** — настраиваемая цепочка подключений с автоматическим переключением при отказе. Живость канала отслеживается двухконтурно: пассивным наблюдением за реальным трафиком и активными пробами по триггеру.

**Защита от утечек** — kill-switch, политика IPv6, блокировка стороннего DoH и QUIC. Реализуется через Windows Filtering Platform из пользовательского режима, без драйвера режима ядра.

## Платформы

| Платформа | Статус |
|---|---|
| Windows 10/11 x64 | 🚧 В разработке |
| Linux — GUI и headless server edition | 📋 Запланировано |
| macOS | 📋 Запланировано |

Демон функционален без графического интерфейса: любое действие GUI выражается вызовом публичного API, а CLI покрывает те же функции. Это заложено с первого дня ради server edition.

## Архитектура

```
GUI (Wails) │ CLI          ← без прав администратора
        ↓ gRPC / named pipe
    Служба (LocalSystem)   ← оркестрация, платформенный слой
        ↓ линковка
   net-core (форк sing-box) ← протоколы, маршрутизация, DNS
```

Ключевые решения задокументированы как ADR:

| [003](docs/adr/ADR-003-tech-stack.md) | Go + Wails |
| [004](docs/adr/ADR-004-ipc-contract.md) | gRPC поверх named pipe |
| [005](docs/adr/ADR-005-dns-strategy.md) | fake-IP с обвязкой безопасности и режим sniffing |
| [006](docs/adr/ADR-006-privilege-security.md) | Разделение привилегий и безопасность IPC |

## Безопасность

Клиент включает службу, работающую с правами LocalSystem. Это исторически уязвимый класс программ. О том, как сообщить о проблеме безопасности, — [SECURITY.md](SECURITY.md).
