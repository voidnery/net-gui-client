Отправная точка: **бинарники не подписаны вообще**. Это ожидаемо на И-0 и является тем состоянием, относительно которого будем отслеживать ухудшение по мере добавления Wintun и службы LocalSystem.

## ⭐ Ключевой пересмотр: подпись стала доступной

[E2](E2-driver-signing.md) заключил, что бесплатного пути к подписи **драйверов** не существует: Azure Trusted Signing их не поддерживает, SignPath Foundation выдаёт только **OV**, а Partner Center требует **EV**.

**Но [ADR-007](../adr/ADR-007-adaptive-interception.md) убрал драйверы из проекта.** Подписывать теперь нужно только:

- `net-gui.exe`, `net-svc.exe`, `net-cli.exe`
- инсталлятор
- (Wintun приходит уже подписанным Microsoft — [E2](E2-driver-signing.md) §2)

Для обычных исполняемых файлов и инсталляторов **OV-сертификата достаточно**. Требование EV относилось исключительно к Partner Center и драйверам.

### Следствие

**SignPath Foundation закрывает всю потребность проекта в подписи — бесплатно.**

| Условие программы | Наш проект |
|---|---|
| Проект с открытым исходным кодом | ✅ да |
| Публично доступная кодовая база | ✅ да (потребуется публичный репозиторий) |
| Признанная OSS-лицензия | ✅ GPL-3.0 |
| Выдаётся сертификат уровня | OV, выпущенный Sectigo на «SignPath Foundation» |

То есть решение Q2 (открытый проект под GPL-3.0), принятое ради возможности линковать sing-box, даёт **второй, незапланированный дивиденд**: бесплатную подпись кода.

Итоговая стоимость подписи для проекта: **$0** вместо $280+/год, которых заказчик обоснованно не хотел.

## Что это даёт по риску R3

| | Без подписи | С OV-подписью через SignPath |
|---|---|---|
| SmartScreen при скачивании | ⚠️ «Неизвестный издатель», предупреждение с блокировкой | Предупреждение снимается по мере наработки репутации |
| Реакция антивирусов на службу и Wintun | Повышенная | Пониженная — подписанные бинарники с прослеживаемым издателем |
| Возможность submission вендорам АВ | Затруднена | Штатная процедура |

R3 уже понижен с «почти гарантирован / высокое» до «средний / средний» решением ADR-007 (убрали драйвер). Бесплатная подпись понижает его дальше.

⚠️ **Важная оговорка:** OV-подпись **не даёт мгновенной репутации в SmartScreen**. Только EV даёт немедленное доверие. С OV предупреждение SmartScreen уходит постепенно, по мере накопления загрузок. Для открытого проекта это приемлемо, но должно быть отражено в документации для ранних пользователей.
