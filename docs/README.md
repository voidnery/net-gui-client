## Решения заказчика

- Лицензия: открытый проект под **GPL-3.0**
- «XRAY» = набор протоколов Xray-core (VMess/Trojan/Shadowsocks/Reality), ядро на наше усмотрение
- Драйвер режима ядра для правил по приложениям — **в MVP**
- Стек — на усмотрение по итогам исследования
- `onAllDown` по умолчанию — `block` (kill-switch)
- Код на Go пишет Claude; параллельно ведётся учебный разбор языка в [gui_client_study.md](gui_client_study.md)
- Приоритет разработки — ранний рабочий сквозной срез, затем наращивание

## Не решено

- Целевая аудитория: массовый пользователь или технические специалисты (влияет на глубину прогрессивного раскрытия в UI)
- Приоритет: скорость MVP против полноты функций
- Визуальный UI-дизайн — отдельная итерация по указанию заказчика
