# Политика безопасности

## Почему этот файл существует

Клиент включает службу Windows, работающую с правами `LocalSystem`, и принимает от непривилегированных процессов команды по межпроцессному каналу. Это исторически уязвимый класс программ: локальное повышение привилегий через такой канал находили в OpenVPN (CVE-2024-4877, CVE-2024-24974), AWS Client VPN (CVE-2025-8069), Cato Client (CVE-2024-6975), IXON VPN (CVE-2025-26168 и др.).

Проект спроектирован с учётом этих прецедентов — см. [ADR-006](docs/adr/ADR-006-privilege-security.md), — но это не гарантия отсутствия ошибок.

## Поддерживаемые версии

Проект находится в ранней разработке. Релизов, пригодных для эксплуатации, пока нет; обновления безопасности выпускаются только для последней версии.

## Как сообщить об уязвимости

**Не открывайте публичный issue для уязвимостей.**

Используйте приватный канал GitHub: вкладка **Security** → **Report a vulnerability**. Так отчёт увидят только сопровождающие.

Полезно приложить:

- версию клиента и версию Windows (сборку);
- описание уязвимости и её последствий;
- шаги воспроизведения или proof-of-concept;
- предполагаемый вектор атаки (локальное повышение привилегий, обход изоляции, утечка трафика мимо туннеля, раскрытие секретов).

## Что нас особенно интересует

| Область | Примеры |
|---|---|
| Межпроцессный канал | Перехват именованного канала, обход проверки клиента, инъекция команд |
| Загрузка кода | Пути, доступные на запись непривилегированному пользователю; подмена библиотек |
| Хранение секретов | Ключи и учётные данные в открытом виде, утечки в логи |
| Утечки трафика | Обход kill-switch, утечки DNS или IPv6, окно при переключении путей |
| Целостность обновлений | Подмена пакета обновления |

## Сроки

Мы стремимся подтвердить получение отчёта в течение нескольких дней и держать вас в курсе хода работ. Гарантированных сроков дать не можем: проект разрабатывается небольшими силами.
